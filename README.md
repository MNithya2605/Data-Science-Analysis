# Data Science Salary Analysis Dashboard

## Overview

The **Data Science Salary Analysis Dashboard** is an interactive Power BI project designed to analyze salary trends in the data science domain across different countries, job roles, company sizes, employment types, and experience levels.
This dashboard helps users gain meaningful insights into compensation patterns within the data industry using visual analytics and business intelligence techniques.

The project was created using **Power BI Desktop** with a dataset containing salary-related information for various data science roles.

---

## Dashboard Features

### 1. Salary Analysis by Company Size

* Compare average salaries across:

  * Large companies
  * Medium companies
  * Small companies
* Identify which company size offers higher compensation.

### 2. Salary Trends by Work Year

* Analyze average salary growth across different years.
* Understand yearly salary variations in the data science industry.

### 3. Country-wise Salary Analysis

* Visual representation of average salaries across countries.
* Compare global salary distributions.

### 4. Employee Residence Salary Insights

* Displays maximum salary earned based on employee residence.
* Highlights countries with the highest salary packages.

### 5. Employment Type Analysis

* Analyze total salary distribution based on:

  * Full-time (FT)
  * Part-time (PT)
  * Contract (CT)
  * Freelance (FL)

### 6. Experience Level Analysis

* Salary comparison based on experience levels:

  * Entry Level (EN)
  * Mid Level (MI)
  * Senior Level (SE)
  * Executive Level (EX)

### 7. Job Title Analysis

* Identify:

  * Most common job roles
  * Highest-paying job titles
  * Salary distribution across different roles

### 8. Interactive Filters

Users can dynamically filter dashboard results using:

* Country
* Company Size
* Experience Level
* Work Year

---

## Key Insights

* Large companies provide the highest average salaries.
* Full-time employees dominate salary distribution.
* Senior-level professionals earn significantly more than entry-level employees.
* Roles like:

  * Principal Data Scientist
  * Director of Data Science
  * Head of Data
    offer the highest salaries.
* Countries such as the US and Japan show higher salary trends compared to others.
